Hands-on labs for Microsoft identity and access, built while studying for
SC-300. All work here is lab work in a test tenant, not production.

IAM-focused IT professional in the UAE. 14 months of hands-on access
administration, now building depth in Microsoft Entra.

5. Access governance: access packages, access reviews, PIM
6. Reading sign-in logs (including KQL)
